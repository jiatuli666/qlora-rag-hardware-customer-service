# 基于 QLoRA 与 RAG 的五金工具垂直领域智能客服系统

> 一个面向五金工具电商产品知识问答场景的垂直领域大模型应用项目。
>
> 项目采用 **QLoRA 轻量化微调 + BGE 中文向量模型 + FAISS 向量检索 + RAG 增强生成**
> 的技术路线，构建针对电动批头、PH2、S2 材质、磁性、长度规格、使用场景等问题的智能客服系统。

---

## 1. 项目简介

本项目针对五金工具电商客服场景，构建一个基于大语言模型的垂直领域智能客服系统。

项目重点解决通用大语言模型在垂直产品问答中容易出现的以下问题：

- 产品规格回答不准确
- PH2、双头、两用头等专业概念理解错误
- 五金工具产品知识缺失
- 客服回答风格不稳定
- 面对具体产品参数时容易产生幻觉
- 缺少针对垂直领域知识的检索能力

系统采用：

**Qwen3-0.6B + QLoRA + BGE + FAISS + RAG**

的技术路线。

其中：

| 模块 | 作用 |
|---|---|
| Qwen3-0.6B | 基础语言模型，负责生成自然语言回答 |
| QLoRA | 低显存条件下进行参数高效微调 |
| BGE | 将用户问题和知识库文本转换为向量 |
| FAISS | 对知识库进行向量相似度检索 |
| RAG | 将检索到的产品知识作为上下文提供给模型 |
| 五金工具知识库 | 提供 PH2、S2、长度、磁性等具体产品知识 |

项目的核心思路是：

> **QLoRA 负责让模型“学会怎么回答”，RAG 负责让模型“回答具体事实”。**
