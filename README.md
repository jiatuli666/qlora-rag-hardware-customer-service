# 基于 QLoRA 与 RAG 的五金工具垂直领域智能客服系统

> 一个面向五金工具产品知识问答场景的垂直领域大模型应用项目。
> 项目采用 QLoRA 轻量化微调 + BGE 中文向量模型 + FAISS 向量检索 + RAG 增强生成，
> 实现针对电动批头、PH2、S2 材质、磁性、规格选择等产品问题的智能问答。

---

## 1. 项目简介

本项目针对五金工具电商客服场景，构建一个基于大语言模型的垂直领域智能客服系统。

项目主要解决通用大语言模型在垂直产品问答中容易出现的：

- 产品规格回答不准确
- 专业概念理解错误
- 产品知识缺失
- 回答格式和客服表达不稳定
- 对具体产品参数产生幻觉

等问题。

系统采用：

**Qwen3-0.6B + QLoRA + BGE + FAISS + RAG**

的技术路线。

其中：

- QLoRA：学习五金工具客服领域的问答任务和表达方式
- RAG：从五金工具知识库中检索具体产品事实
- BGE：将用户问题和知识库文本转换为向量
- FAISS：完成 Top-K 相似度检索
- Qwen3-0.6B：结合检索结果生成最终回答
